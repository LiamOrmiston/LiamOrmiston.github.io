      4. Generate assignments

      Generates a valid one-way assignment (no self-matches, all rules respected) and encodes it with Base64 so it’s not shown in plain text. It’s obfuscation, not encryption.

      After downloading, place assignments.json in the secret-santa/ folder (same folder as reveal.html) and send friends the link to reveal.html.
